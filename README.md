# 📦 Payroll App

# Aulia Azmi Al Farisy X RPL B

Aplikasi payroll (payroll app) adalah perangkat lunak atau sistem yang dirancang khusus untuk membantu perusahaan menghitung, mengelola, dan memproses gaji karyawan secara otomatis, akurat, dan efisien.

## 🚀 Requirements

Pastikan sudah terinstall:

- PHP >= 8.x
- Composer
- MySQL / PostgreSQL / SQLite
- Node.js & npm
- Git

## 📥 Cara Install

Clone repository:

```bash
git clone https://github.com/DionAhza/Payroll_app/
```

```bash
cd nama-project
```

```bash
composer install
```

```bash
copy .env.example .env
```

```bash
php artisan key:generate
```

```bash
php artisan migrate
```

```bash
php artisan serve
```
